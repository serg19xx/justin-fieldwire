FieldWire — what changed on November 3, 2026

Task assignment fix: changing who is responsible for a task. All changes are live.

In short:
  • You can now take a worker off a task and set it back to "Unassigned — Justin Kearney (Project Manager)". Before, the change did not save.
  • The list of people in a task now also shows people who are already busy on another task that day, with a "busy" label, so you can still pick them.
  • Only field roles (Foreman, Worker, Architect) appear in that list. Other roles, such as Doctor, no longer appear.

1. Setting a task back to "Unassigned"

What was wrong

On the task "Order 20 sheets 1/2 8' and 2 5/8 drywall" you tried to change the responsible person from Dale Bowerbank to Unassigned — Justin Kearney (Project Manager). After Save, Dale was still shown as responsible.

The task form did not tell the server that the responsible person had been removed. The server received no change for that field and kept Dale. In some cases the form could also switch your selection back to Dale on its own while the page was still loading the list of people.

How it works now

  • Choosing Unassigned and pressing Save removes the worker from the task. The project manager is responsible until someone is picked again.
  • The worker is also removed from the task's Team section.
  • Once you pick a person (or Unassigned) in the form, the form no longer changes your choice by itself.
Already fixed for you: the drywall order task is now Unassigned, as you wanted.

2. Busy people now stay in the list

What was wrong

After the task became Unassigned, Dale disappeared from the list of people you could pick. The system hid everyone who was already on another task with overlapping dates, in any project. On November 4 Dale is already responsible for "Drywall Removal & Replace", so he was treated as unavailable. In practice a foreman often runs several tasks on the same day, so hiding him was wrong.

How it works now

  • Busy people are shown in the list and can be selected. Next to their name you see the task that keeps them busy, for example:
    Dale Bowerbank (Foreman) — busy: Drywall Removal & Replace
  • If a person is on several tasks those days, the first one is shown with +N for the rest, for example — busy: Drywall Removal & Replace +2.
  • The label is only a reminder. It does not block you from assigning the person.

3. Only field roles in the list

The list also showed Oyeleke Olafeye Oyedotun (Doctor). It now shows only people who can work on site: Foreman, Worker and Architect. This matches the rule that was already used when creating a new task.

What to check

  1. Refresh the page once (Cmd + Shift + R on Mac, Ctrl + F5 on Windows) so the browser loads the new version.
  2. Open My Projects → Ellesmere Medical Clinic & Pharmacy → Jobsite and click Edit on any task.
  3. In Who does the work → Own worker, open the list: Dale is there, with a "busy" label if he is on another task that day.
  4. Select Unassigned or another person and press Save. The task card shows the new choice.
Good to know: when you switch a task from Contractor to Own worker, you still need to pick a specific person; it cannot be saved as Unassigned in that one case. This has not changed.

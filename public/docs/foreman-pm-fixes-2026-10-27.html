Foreman & PM Fixes — What Changed and What We Need From You

This note covers the six items from Foreman Fixes (tested with Dale's account, dale@CareSpaces.Pro), the four items from PM Fixes (Justin's account), plus a security fix to logins. The first part explains what is different in the app. The second part lists the things only you can do. Without them, some features (SMS reminders, KM totals) will appear to "not work" even though the software is ready.

Part 1 — What changed

1. Foreman now sees the PM Schedule

A foreman's Timesheet and Calendar now show the schedule the Project Manager publishes, the same one the PM sees. Only published weeks are shown. A week the PM is still editing (draft) stays hidden from workers until it is published.

2. Weekly Timesheet (horizontal, Mon–Sun)

The Timesheet is now one week at a time, with a column for each day Monday to Sunday. Use the arrows to move between weeks and This week to jump back. Each day shows the project, its address, the expected start and end times, the hours scheduled, the hours actually worked, and the KM. At the bottom are three totals for the week: - Total Hours Scheduled: the PM's expected start to expected end for each day, minus a 30-minute break. - Total Hours Worked: from the worker's Start day to End day, minus the same break. - Total KM: the sum of the KM values the PM enters in the Schedule (see Part 2, item 3).

On phones the week scrolls sideways, so each day stays readable on a small screen.

3. Clock in / clock out with a photo, plus SMS reminders

  • Start day and End day now require a photo taken on site. On a phone the camera opens directly. The punch is not saved without a photo.
  • The PM sees the actual start and end times in the project Schedule (columns Act start and Act end). A Photo button there opens the picture taken at that punch.
  • SMS reminders are now based on the published PM Schedule:
    • If a worker has not pressed Start day within 5 minutes of their expected start, they get a text.
    • If they have started but not pressed End day within 5 minutes of their expected end, they get a text.
    • Each reminder is sent at most once per worker per day.
    • Saturdays and Sundays are covered as well, if the PM schedules work on those days.

4. Foreman sees all of their projects

Projects where the person is set as Foreman now appear in Tasks and Calendar, even if no tasks are assigned to them yet. Before this fix, Dale only saw Ellesmere. CareSpace.Pro now shows up as well.

5. Daily notes moved from Tasks to the Calendar

The PM's daily notes ("Notes from PM") no longer appear on the Tasks page. They are in the Calendar: each scheduled day appears as an orange entry, and tapping it opens a pop-up with the project, times, KM and the PM's note.

6. Foreman sees only their own tasks

The My tasks / All tasks switch is removed for foremen. They see only tasks assigned to them.

PM fixes (from PM Fixes, account justin.Kearney@me.com)

  1. My Projects hides completed projects. Projects with status Completed Project (or lifecycle Done) are hidden by default, so only active work shows. Tick Show completed to bring them back. The checkbox shows how many are hidden. Choosing Completed Project in the status filter also shows them.
  2. Schedule time fields are wider. Exp start and Exp end now show the full time, for example "08:00 a.m.". On a phone the Schedule table scrolls sideways, like the Timesheet.
  3. Schedule totals at the bottom. Below the days you now see Total hours scheduled (Exp end − Exp start), Total hours worked (Act end − Act start) and Total km (sum of the Km column) for the selected worker and period.
  4. Sort projects by status. Click the Status column header, or pick Status in Sort by…. Projects are ordered by stage (Initial Contact Lead → … → Construction → Completed Project), or the reverse. Sorting by project name and by client also works now.
  5. New task: address and estimated time. When you create a task, the Address is filled in from the project automatically (you can still change it). The Start/End date and time fields are replaced by Estimated Time to Complete (Days / Hours / Minutes). Planned dates are set for you: the task starts on the selected day (or today) and lasts as many days as the estimate, so the Gantt chart and calendar keep working. Use Set dates manually if you need specific dates. When editing a task, the dates are under Edit planned dates. The estimate is shown in the task details.

Security fix: logins

We found that the server was not fully checking login sessions. This is now fixed. What users will notice: - After this update is deployed, everyone has to log in once more. This is expected and happens only once. - After that, people stay logged in as long as they use the app at least once a week. If someone does not open the app for more than 7 days, they are asked to log in again. - The existing rule still applies: after 30 minutes with no activity in an open browser tab, the user is logged out.

4. PM must fill in expected start and end times
